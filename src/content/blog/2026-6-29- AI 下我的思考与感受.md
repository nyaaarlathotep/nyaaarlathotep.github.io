# 大模型大潮下我的思考与感受

## 前言

大模型在一夜之间摧毁了太多技术相关的积累，就像泥头车碾过小猫咪，势不可挡，毫不留情。当我新冒出一些点子，思考是否能丰富成一篇博客的时候，转念一想，这些点子从 大模型 大人手下都无法存活，任何一个 大模型 随便转转就比我能思考产出的博客丰富的时候，我又有什么写下去的必要呢？这些点子就像手写编程一样鸡肋。

我们就在历史中。每一刻，目睹事件的流逝变化，带来的感触，对于未来的迷茫，期待，猜想，是历史更重要的内容，我们都在见证历史。看史密斯吃面的人想不到今天的 大模型，我也曾一直唱衰，不看好 大模型，但 大模型 发展的现状已经毫无疑问了。我对大模型的现状如何思考？我能想到明天的大模型吗？就记录下我的想法与思考吧。

## 历史与现状

### 发展

2023 年，GPT 3.5 告诉了我们什么是大模型。

2024 年，agent，RAG 的发展，上下文不断拓宽，copilot 自动补全，AI 原生 IDE 如 cursor 出现。

2025 年，多模态也不断发展，，MCP 给了模型进入我们世界的方式。

2026 年，OpenClaw 爆火，harness 等工程，继续增强大模型能力，完善工程能力。

### 现状

现在是 2026 年中，工作中，我的代码基本全部由 大模型 生成了，平时需要动手的是提示词与配置工作。大模型 写成的代码微观上足够优秀足够考虑周全，基本比我强。当下最好用的是 opus 4.8(1M context)。新时代的业务程序员不必再深入学习细节，只需**把握需求的边界，掌握沟通技巧与工程能力，定好约束确定雏形设计**，在附加订阅与转动，就能得到令人满意的结果，手写代码至此完全成为非遗传承了。

平时生活中，有知识性的问题，或者顾问咨询类型的问题，甚至人际交往中的问题，都可以咨询 大模型，能为我们提供极大的帮助，至少也能拓宽思路，给予我们更多思考的方向。

人工智能助手，类似 hermes，可以接入 Telegram，QQ，可以承担很多实习生级别的任务，类似于 Excel 处理生成，人工自然语言转化的定时提醒，配合 MCP 可以做更多事情。

酒馆，已经可以玩到复杂有趣的角色扮演了，丰富真实，让自闭症也能有和朋友一起跑团的感受。

所有应用，注意，我是说所有（除了 PDD），都在尝试推出自己的 agent 助手，让用户可以用自然语言进行操作。agent fever。我现在也在做 agent 相关的开发工作。

中老年人的渗透率也在随着时间不断增加。

同时，随着依赖大模型的人越来越多，已经有很多人信大模型而不是现实世界了，搞出很多抽象案例。和大模型聊天可比和人聊天舒服多了，可以猜想，未来会有很多精神上高程度依赖大模型的人了，这又是社会研究上的课题了。

## 体会与心情

### 过去

在 2023 年左右，我是不看好大模型的，我认为大模型会很快触及它的上限，包括模型能力本身的上限与模型应用的上限，我不认同这种基于概率的方式，算不上”智能“，它只是重复。

随着大模型继续的发展，大模型本身的能力还在不断进化，新名词一个接着一个出现，目不暇接。我也在不断的使用过程中理解了：这是不可阻挡的趋势，我必须要顺应趋势。而且不管它是不是智能，有没有上限，当前的大模型的能力也在不断增强的结果下，强的离谱了，它也足以带来巨大广阔的应用前景。这是下一次的技术革命，和 web2，移动互联网等级别的革命，会带来新的丰富的机会，会洗牌，去除没能力的参加者。

再说回来，无论我认不认同大模型，我也确实的理解与感受到，有很多人认为这就是我们的未来与方向了，那么为了在他们，融入他们，获得他们的认同，进而获得我自己的发展，我也需要这样认为。泡沫是否由此产生？到底有多少人是被裹挟的。这也是一种意识形态了。

### 现在

当大模型在辛苦旋转的时候，我的内心是惬意释然的，可以上个厕所，接一杯水，休息一下。大模型指出可能存在的问题，提醒我需求不明确的点的时候，我是羞愧的，庆幸的，赞赏的。大模型转完了我的需求的时候，我是空虚的，恐惧的，我可以被完全替代，我曾经的手艺已经被时代抛弃了。

我也看到很多新人，对于使用大模型的思虑，认为工作全部都是大模型代劳了，而自己没有学到东西。这些忧虑，和那些上个时代看不起使用 IDE，要默写库函数 API 的人，是一种意思吗？我庆幸我处在两端，我实实在在手写过很多代码，有基础，但这些基础是否在未来有用，我就不知道了。

MCP 已经实际上让 大模型 进入了我们的世界，过去科幻一般的人工智能助手已经实现了，这放在几年前谁能想到。

## 哪些是炒作

大模型的端到端给了像魔法一样解决了太多问题，还没带来更多副作用，隐藏了复杂度，人类可太喜欢这种事情了，特别是老板。那么利用这种端到端，能实现我们梦想中的“通用“吗，让我们远离复杂度，保持双手干净吗，我不好说。

比如，具身智能。我在这不是说这个东西无法实现，而是这里的通用，代价太大，当你能发展它或者完全使用它的时候，它的性价比或者其他原因，你不会使用它。比如说，为什么不用几个常用动作的机械臂来替换一个用在各处的机器人？做这项业务的人会回答你，这些问题在发展中会不断优化，解决，问题的解决方案会被逐渐训练，成本会逐渐下降，果真如此吗，慢慢尝试吧，烧烧有钱人的钱，做做探索。

## 思考

### 技术进步让生活变好了吗

大模型 带来的生产力有没有让我们的社会变得更好？振聋发聩的质问了，更深层导向的思考就是：新技术会不会让我们的生活变得更好？怎么导向才能让新技术真的让我们的生活变好。

![AI 多久会让经济变好.png](/images/AI 多久会让经济变好.png)

大公司在寻求大模型技术的应用方向的时候，宁愿疯狂压榨员工，增加工时，给出很多不切实际的方向做尝试，浪费人力，把牛奶倒进河里。然后裁员，用大模型节约人力。那么从整体看，这份技术剥夺一部分可以被大模型替代的人的工作，然后给了我们用自然语言对话点奶茶的能力，然后加剧分配的不均衡。这对经济来说是好事还是坏事。

都在说大模型带来技术平权，但现在看至少带来了裁员。

### 拿着锤子找钉子

程序员就会遇到这种情况：空有实现功能的能力，却不知道可以实现什么，不知道哪里可以施展能力，可以解决什么问题。大模型不存在的时候就已经是这样，所以人人都会做个 todoList。大模型更凸显了这个问题，只是锤子质量更好了罢了。

这也是为什么创业难，我们实际上很难找到真正的需求在哪，知道用户需要什么。

### 市场

泡沫会破吗，token 经济何去何从，除了程序员和玩酒馆的谁会买账，如果只用 chat 形式的大模型，那么它有这么不可或缺吗。

deepseek 和华为的卡会笑到最后吗？很有可能，如果如我所想，只是训练与概率，那么就没有哪家公司的模型可以垄断，具有稀缺性，只是时间问题罢了。

大模型的这种堆料的训练形式是否有上限或者说我们是否已经触及了上限？

大模型的预期，或者说美股看起来是可以左脚踩右脚无限飞升的，大公司之间互相预定订单，炒热预期与股价。光通信和存储已经让人眼红耳热了，天天有贷款 ALL IN 胜利的牛人，我能保持冷静吗，大家伙能保持冷静吗，nasdaq 下次仍然能简简单单修复自己吗？又回到上面提到的意识形态的问题了，这不是我怎么认为，是我认为其他人怎么认为，这也是市场永恒的游戏主题。

## 展望

其实关于这个部分我也想不出什么高见，我要真能想出点什么可能早就去创业了。

高度依赖知识检索和咨询的行业必将受到猛烈冲击，例如律师、咨询顾问等业务，都会逐渐被配备了相关知识库的 Agent 所取代。这个过程已经进展了很大一部分，未来只会更加剧烈。

随着大模型相关内容进一步渗透进传统行业，MCP 能提供的接口会越来越多。个人助手能帮我们处理的事情会更广，让我们的生活变得更加舒适。

在个人助手上，我认为很多用户也不知道自己想要什么，所以需要助手主动的发起聊天，和用户交流以明确需求。就像 skill grill-me 一样，可能可以增加一个定期的询问的定时任务？这都是可以的。

具备高级文书处理能力（替代甚至超越 Excel 等办公软件功能）的智能体会变得异常强大，并且主打“开箱即用”。在这个层面上，“开箱即用”的用户体验与市场宣传，甚至比 agent 的实际能力更重要。

## 总结

这篇博客是我混乱发散的思考，想到哪写到哪。而写这篇文章的时候我也才注意到，我已经把 **AI 和大模型**混用了，两者现在已经是近义词了，令人感叹。

我只希望大模型能不要替代我吧，大模型爷已经要把我们都杀光了。
